# Travel With Alina

A React Native travel application with customer rewards and service workflows.

## Product areas

- Authentication and profile management
- Tours, purchases, and user documents
- In-app chat
- Reward balance and bonus shop
- AdMob rewarded ads with daily limits and cooldown logic
- API-driven data layer with React Query and Axios

## Stack

React Native · Expo · TypeScript · React Navigation · React Query · NativeWind · AdMob

## Run locally

1. Copy `.env.example` to `.env` and add local configuration values.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start Expo:

   ```bash
   npm run start
   ```

Use `npm run android` or `npm run ios` to run a native build. Do not commit credentials to `.env`.
